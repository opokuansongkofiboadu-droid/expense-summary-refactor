# Expense Summary Refactor

## Description
A command-line Python program that collects expense records, validates the input, calculates totals by category, displays a summary, and exports the summary to a text file.

## Features
- Collects expense category and amount
- Cleans and validates category input
- Rejects invalid or negative amounts
- Calculates total spending
- Calculates totals for each category
- Displays a formatted expense summary
- Exports the summary to `expense_report.txt`

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run:

```bash
python expense_tracker.py
4. Enter three expense records when prompted.
5. View the summary in the terminal.
6. Check expense_report.txt for the exported report.
